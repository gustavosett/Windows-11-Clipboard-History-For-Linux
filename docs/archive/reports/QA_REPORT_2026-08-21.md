### Honest limitation / محدودیت صادقانه
The sandbox cannot compile Rust (registry network blocked). Mitigations:
syntax gate 47/47, a conservative mechanical split (`use super::*`,
`pub(super)` audit table), and CI as the authoritative compiler — the first
push runs the full `cargo` matrix.
سندباکس امکان کامپایل Rust را ندارد؛ سینتکس بررسی شد، تفکیک محافظه‌کارانه
انجام شد و CI به‌عنوان مرجع نهایی کامپایل در نظر گرفته شده است.

## 2. Delivered changes / تغییرات تحویل‌شده

### A. Supply chain (ADR-0005 → Implemented) / زنجیرهٔ تأمین
1. **CI now blocks** on quality (lint + coverage + `cargo test` + clippy),
   security (`cargo audit` + `cargo deny` + `npm audit`, no
   `continue-on-error`), and a release-binary smoke test under `xvfb-run`.
2. **Release pipeline** publishes `SHA256SUMS`, **per-artifact SPDX SBOMs**
   (syft), and **SLSA build-provenance** attestations; every URL points at
   `Mahdi-Arts/Windows-11-Style-Clipboard-History-Manager`; optional AUR/Cloudsmith
   channels are gated on repository secrets.
3. `src-tauri/deny.toml` — advisories / licenses / bans / sources policy.
4. Least-privilege CI (`contents: read`, `persist-credentials: false`,
   concurrency groups).

> ⚠️ The two `.github/workflows/*.yml` files could not be pushed by this
> session's token (GitHub App without `workflows` scope). They are committed
> locally and bundled at `docs/patches/hardened-ci-workflows.patch`
> (`git am docs/patches/hardened-ci-workflows.patch`).

### B. Security (ADR-0006) / امنیت
- `KeyBackend` (File ↔ Secret Service) with the fail-closed
  `history.key.check` integrity marker; marker-mismatch refuses to load
  (unit-tested); reversible verified migrations (`secret-tool` read-back);
  Settings → Privacy UI (bilingual, a11y-labelled) exposes status,
  availability, migration, and the restart notice.
- Settings persistence + validation for `history_key_backend` (Rust + TS).

### C. Architecture (ADR-0007) / معماری
- `clipboard_manager.rs` (1250 lines) → package of 5 focused submodules
  (`types`, `persistence`, `deduplication`, `history_access`,
  `clipboard_write`); cross-module internals are `pub(super)`; public API
  unchanged for all callers.
- New `get_history_page(limit, offset)` command — server-clamped to
  `1..=MAX_PAGE_SIZE (200)`; `useClipboardHistory({ pageSize })` +
  `loadMore()`; pure, 100%-covered helpers in `src/utils/pagination.ts`.
- Shared `clipboard_manager::data_dir()` (single source of truth).

### D. Documentation (bilingual) / مستندات
- ADR-0006, ADR-0007 added; ADR-0005 → Implemented; THREAT_MODEL,
  ARCHITECTURE, README, CHANGELOG (Unreleased) all synced — **every claim in
  the README is now true of the repo**.
- `packaging/README.md` rewritten as the full bilingual
  `.deb` → GitHub Release → Flatpak deployment guide (layout table, sandbox
  policy matrix, Flathub submission, checklists).
- CONTRIBUTING: bilingual comment policy, hooks, dependency-license policy.

### E. Hygiene & DX / بهداشت و تجربهٔ توسعه
- `.kilo/` untracked; CODEOWNERS (security paths); root reports →
  `docs/reports/`; zero-dependency git hooks (`make hooks`); Makefile
  `hooks` target + cargo-deny in `audit`.
